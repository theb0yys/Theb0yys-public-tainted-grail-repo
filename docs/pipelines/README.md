# Older Authoring-Pipeline Links

> **Compatibility page.** These paths are retained so old bookmarks do not break.

The previous versions of `docs/pipelines/` incorrectly presented structures visible in Merlin Workshop as if they were complete processes for adding genuinely new FoA content.

That interpretation has been withdrawn.

Merlin Workshop remains:

- the official Questline replacement-oriented modding toolkit;
- useful for supported Addressables/asset replacement work;
- a first-party source of information about native types, GUIDs, addresses and relationships.

It does **not** supply a general registration/integration process for arbitrary new items, weapons, armour, creatures, spells or recipes.

Use the current handbook instead:

- [Technical Handbook](../REFERENCE_MAP.md)
- [Items: Proven Custom Item Integration](../reference/ITEMS.md)
- [Content Domains](../reference/CONTENT_DOMAINS.md)
- [Assets, Addressables, and Presentation](../reference/ASSETS.md)
- [Research Method](../reference/RESEARCH_METHOD.md)

The old filenames below remain as redirects only.
