# Saving and Persistence

Use these guides when a feature must survive save/load or when you need to understand whether a runtime object belongs in native save state at all. Treat current-session success, native persistence, and mod-owned sidecar state as separate problems.

Native ownership: [Saving/persistence](../../../knowledge/systems/world/saving-persistence.md) and [Persistence architecture](../../../knowledge/systems/core/persistence-architecture.md). Runtime success alone does not prove save safety.
