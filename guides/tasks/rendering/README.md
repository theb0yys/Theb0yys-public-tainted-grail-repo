# Rendering

Use these guides when a visual change involves FoA's specialized rendering systems rather than a normal Unity Renderer. Identify whether Drake, Kandra, Medusa, Leshy, HLOD, or another owner controls the runtime representation before changing it.

Identify the owner first: [Drake](../../../knowledge/systems/presentation/drake/README.md), [Kandra](../../../knowledge/systems/presentation/kandra/README.md), [Medusa](../../../knowledge/systems/presentation/medusa/README.md), [Leshy](../../../knowledge/systems/presentation/leshy/README.md), [HLOD](../../../knowledge/systems/presentation/hlod/README.md). See [rendering case studies](../../../research/case-studies/rendering/README.md).
