# Armour Importer Pipeline

The complete reproducible armour process is maintained as a staged project tree:

**[Open the Armour Importation Pipeline](../../../pipelines/armour/README.md)**

It separates source/provenance, source-to-target rig mapping, deformation, Kandra conversion, package validation, Kandra registration, custom item/native clothes ownership, runtime visual/equip validation, persistence/release, and failure recovery.

Technical owners remain [Armour](../../../knowledge/systems/gameplay/armour.md) and [Kandra](../../../knowledge/systems/presentation/kandra/README.md).
