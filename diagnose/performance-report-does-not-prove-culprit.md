# Performance Report Does Not Prove the Culprit

If a report shows poor frame pacing and lists many loaded mods, do not rank those mods by blame.

## Next evidence

1. Reproduce the same save/settings/workload.
2. Capture a native/engine baseline where practical.
3. Compare with only the monitor enabled.
4. Add the normal mod stack.
5. Isolate suspected components one at a time.
6. Use owned-code timers or a profiler before naming a specific method/subsystem.

Treat the report as a **triage packet**, not a verdict.
