# 01 - Windows Setup

This guide assumes Windows because the current FoA loader/tooling evidence in this repository is Windows-focused.

## Runtime plug-in path

You need:

1. **Tainted Grail: The Fall of Avalon installed locally.**
2. **The correct BepInEx lane already installed and able to start.**
3. **Visual Studio 2022 Community** or another editor/build environment capable of building the supplied C# project.
4. The repository files on your machine.

### Easiest Visual Studio setup

Open **Visual Studio Installer**.

Select your Visual Studio installation -> **Modify**.

Install the **.NET desktop development** workload.

For the legacy Mono template, also make sure the **.NET Framework 4.7.2 targeting pack/developer pack** is available.

The current IL2CPP starter targets net6.0; the legacy Mono starter targets net472.

### Get this repository

If you do not use Git yet:

1. Open the repository page on GitHub.
2. Click **Code**.
3. Choose **Download ZIP**.
4. Extract it somewhere outside the game folder, for example:

~~~text
C:\TGModding\community-starter
~~~

If you already use Git, clone normally instead.

## Content-authoring path

For the Merlin Workshop content pipeline, the inspected project currently reports:

~~~text
Unity Editor 6000.0.60f1
~~~

Merlin Workshop's own README explicitly says **do not use GitHub's autogenerated ZIP for the toolkit**. Use its release archive or a proper Git checkout/fork.

Recommended beginner shape:

~~~text
C:\TGModding\
  community-starter\
  merlin-workshop\
  MyMods\
~~~

Keep these separate from the game installation.

## Checkpoint

Before continuing, you should have:

- the game installed;
- a normal modding workspace outside the game;
- the starter repo available locally;
- your code editor/build tools installed.

For runtime plug-ins, BepInEx must already start successfully before your own plug-in becomes part of the debugging problem.
