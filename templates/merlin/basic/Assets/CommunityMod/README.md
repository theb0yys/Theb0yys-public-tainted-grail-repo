# Community Mod Content Root

Rename this folder to your mod/content identity before authoring.

Suggested subfolders as needed:

- `Data/`
- `Prefabs/`
- `Scenes/`
- `Scripts/`

Only create lanes your Merlin project actually supports. Keep generated Unity `.meta` files with their matching assets.

Do not place copied game assets, extracted commercial content, saves or generated game assemblies in this public template.
