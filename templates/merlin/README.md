# Merlin Templates

Questline maintains the actual Merlin Unity project: https://github.com/AR-Questline/merlin-workshop

Use [basic/](basic/) as a **content overlay starter** for that project. It gives you a clean owned content root without copying or recreating the Merlin SDK/project itself.

This repository intentionally does not maintain a parallel Merlin Unity project. Community templates here should add narrow reusable patterns while upstream remains authoritative for the editor/toolkit.
