# Hooks

Use these pages when you need an exact method or lifecycle point to observe or change behavior.

- [Hook catalogue](catalogue.md) — known patch targets and what they have been used for.
- [Lifecycle and hook timing](lifecycle.md) — how to choose a target based on what is ready before and after it runs.
