# Domain Authoring Packets

These packets are mandatory before a large domain page is split or migrated.

They translate reviewed private evidence into a **public-safe source map and reader model** before any file movement happens.

Each packet records:
- reader questions;
- document archetypes;
- canonical native owners;
- prerequisites;
- public source set;
- private-evidence conclusions without making the public docs depend on private access;
- claims to teach;
- failure/correction history worth preserving;
- required diagrams;
- worked-example candidates;
- evidence lanes;
- public/private exclusions;
- canonical destinations;
- completion checks.

The detailed private provenance remains in the maintainer's private research intake. Public pages must be independently useful without that access.
