# Private-to-Public Authoring Process

Use this workflow for mining the private engineering corpus.

```text
private evidence
→ select one reusable knowledge unit
→ extract claims (not prose)
→ reconstruct owner/lifecycle/reasoning
→ preserve meaningful failures/corrections
→ choose public archetype
→ write clean-room explanation
→ link canonical system/mechanic/reference
→ state evidence boundaries
→ review against private evidence
→ validate public example separately when executable
```

## Stop if

- the source actually contains several independent questions;
- a consequential claim has no inspectable support;
- only the final code path is known but not why it works;
- simplification would broaden the claim;
- private success is being used as proof that a newly written public example was executed.

The publication ledger records what has actually been extracted.
