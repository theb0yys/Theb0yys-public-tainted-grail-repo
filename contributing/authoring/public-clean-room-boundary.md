# Public Clean-Room Boundary

Public pages may contain:

- independently authored explanations;
- exact type/method names where needed;
- bounded pseudocode or public-safe example code;
- architecture diagrams;
- evidence status and version scope;
- lessons extracted from failures/corrections.

Do not publish by default:

- bulk decompiled game source;
- private production implementation source;
- extracted commercial assets/bundles;
- saves;
- unrestricted private logs;
- personal machine paths;
- credentials;
- unreviewed speculative research.

A public explanation should be sufficient to teach the mechanism without becoming a dump of the private workspace.
