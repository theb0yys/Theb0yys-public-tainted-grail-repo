# Visible Talent Group ≠ Native Proficiency

The character screen exposes thematic groups such as Critical Hits, Daggers, Health and Attack Speed.

Research did not find a one-to-one native proficiency for every visible group.

The project therefore routes confirmed native practice into a **separate branch/overlay model** instead of inventing hidden vanilla XP stores.

## Lesson

UI taxonomy, native data taxonomy and mod design taxonomy may all differ.

Document which one you are talking about.
