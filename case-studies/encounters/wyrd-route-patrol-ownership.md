# Wyrd Route Patrol: Three Owners, One Feature

The route-patrol design deliberately avoided putting everything in Wyrd Hunt.

- Wyrd Hunt says **whether strict exposure is confirmed**.
- Avalon Core says **which exact route is reviewed/authorized**.
- Living Avalon says **which actor it owns and how it is placed/bound/cleaned up**.

Native AI still owns detection/combat.

## Lesson

A feature that crosses systems does not need one giant owner. It needs explicit responsibility boundaries and one-way read-only dependencies where possible.
