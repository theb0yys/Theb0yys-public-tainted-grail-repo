# Human Native-Ally Proof

The human companion research did not start by “recruiting any NPC”.

It selected one reviewed repetitive/non-unique outlaw template and applied the same native summon-faction + `NpcHeroPetAlly` ownership pattern already used for temporary creature companions.

## Deliberately blocked

- existing NPC conversion;
- named/story/quest NPCs;
- persistence;
- recruitment/roster save;
- custom target selection;
- custom follow/pathing;
- dialogue/story mutation;
- inventory/equipment/leveling.

## Lesson

Prove one safe temporary actor class before turning the result into a general “human companion” claim.
