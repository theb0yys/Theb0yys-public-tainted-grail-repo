# Auto-Unlock Without Bypassing Every Lock Rule

The lockpicking research distinguishes:

- key-only locks;
- locks the hero can open with a key;
- ordinary lockpickable locks;
- active lockpicking interactions.

A safe “auto” feature should only skip the minigame for the last category and still use the native unlock/crime path.

## Lesson

Convenience automation should skip the **interaction**, not erase the underlying eligibility/progression/legal rules.
