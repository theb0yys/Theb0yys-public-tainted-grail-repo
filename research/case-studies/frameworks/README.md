# Framework / Tooling Case Studies

These case studies cover shared-framework work: deciding when a capability belongs in common infrastructure, defining public contracts, keeping consumers fail-closed, and avoiding dependencies on private framework internals.

Use them when a feature has outgrown one mod and you need to understand what should become shared infrastructure, what should remain feature-owned, and how consumers should discover or depend on it.
