# Persistence Case Studies

These case studies cover save/load and persistence problems, including custom identities, restore timing, session-only state, sidecar research, and cases where a feature worked live but failed after restart or load.

Use them when you need to see how a current-session success was tested against cold restart, restore ordering, missing-mod behavior, or deliberately non-saved state.
