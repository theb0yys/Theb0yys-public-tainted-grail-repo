# Patch Notes Can Invalidate an Old Fix

Research for **Oh Merry Men** and **Over My Dead Bodies** found official patch history addressing related progression/blocker issues.

Instead of immediately implementing historical community fixes, both projects remained inactive pending current-build reproduction.

## Lesson

A compatibility mod can become harmful if it re-applies a workaround after the base game has fixed the underlying bug.

Current-build reproduction is part of the bugfix contract.
