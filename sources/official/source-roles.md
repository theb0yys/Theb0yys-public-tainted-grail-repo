# What Official FoA Modding Sources Prove

Official Questline material is the strongest source for the public surfaces Questline intentionally exposes.

## Merlin's Workshop

Repository:

https://github.com/AR-Questline/merlin-workshop

Wiki:

https://github.com/AR-Questline/merlin-workshop/wiki

Use these sources to establish:

- documented Merlin project structure;
- replacement/content authoring surfaces exposed by Questline;
- official asset/address/GUID relationships where published;
- documented build/export procedures.

## Limits

Official Merlin material does not automatically prove:

- arbitrary new-content registration through FoA native registries;
- BepInEx runtime ownership;
- private native methods;
- persistence behavior outside the documented toolkit;
- a reverse-engineered hook simply because it interacts with Merlin content.

## Citation rule

When documenting an official capability:

1. cite the exact repository/wiki page;
2. state what it explicitly supports;
3. separate that from any static/runtime evidence added by this project;
4. do not label reverse-engineered behavior “official”.

For internal game evidence, follow [Sources and Evidence](../README.md) and the [Public Evidence Standard](../evidence-standard.md).
