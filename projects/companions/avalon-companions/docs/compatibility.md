## Known conflicts

- The companion UI input-lock Harmony patches return immediately unless the custom dialogue interface or debug panel is visible.
- The opt-in one-session candidate roster can overlap with summon, combat AI, faction, and respawn mods when enabled.
- Future companion behavior may overlap with summon, respawn, world population, combat AI, stealth, crime, and quest-state mods.

## Version notes

- Mono branch and BepInEx v5 are assumed from repo baseline research.
- Default IL2CPP branch is not supported by this scaffold.
