## Notes

- Version 0.1.11 keeps the 0.1.9 Harmony panel input lock and only changes the optional proof-panel style/scope shell. Wider compatibility should still be revalidated alongside Avalon Companions, FoA Mod Manager, Tainted Interface, cheat panels, and other UI/input mods.
- Safe proof spawn should only be used on a throwaway save with an explicit reviewed non-unique template GUID.
- Actor scanner output is plugin-owned CSV evidence only and should be generated on a throwaway save during this proof stage.
- One-session native ally proof should only be used on a throwaway save with an explicit reviewed non-unique template GUID. It affects only the plugin-owned spawned proof actor, not existing NPCs or global faction tables.
- Native quick commands are attached only to the active plugin-owned proof actor after `NpcHeroPetAlly` is present, but the native interaction path did not work in live testing. The proof panel is the current command path. Version 0.1.8 Hold is a runtime movement lock for the active proof actor only; true Stay/Wait and saved hold positions are not implemented.
- Lifecycle diagnostics write plugin-owned `human-proof-lifecycle.csv` rows only while proof lifecycle events occur or while an active proof actor is guarded.
- Future human NPC behavior may conflict with Avalon Companions, Avalon Core, Living Avalon, summon mods, population mods, faction/crime mods, quest-state mods, dialogue mods, and save/load behavior.
