# Glossary

Use these pages for project terminology before interpreting capability or evidence claims.

- [Runtime and evidence terms](runtime-and-evidence.md)
- [Ownership and content terms](ownership-and-content.md)

Core quick terms:

- **Native owner** — the game system that actually owns a responsibility/lifecycle.
- **Mono** — managed FoA runtime lane / BepInEx 5.
- **IL2CPP** — FoA IL2CPP runtime lane / BepInEx 6 + Il2CppInterop.
- **BepInEx** — community plug-in loader.
- **Harmony / HarmonyX** — runtime method patching.
- **Merlin's Workshop** — Questline's official Unity/Addressables modding project.
- **Static evidence** — source/metadata/decompilation evidence without live observation.
- **Runtime evidence** — behavior directly observed in the target environment.

See [Evidence standard](../../sources/evidence-standard.md).
