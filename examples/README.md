# Examples

Examples are deliberately smaller than real mods.

Start with:

- \`mono-harmony-self-test/\` — learn the mechanics of a Harmony patch without touching game code.
- \`proven-paths/\` — clean-room templates that preserve reusable mechanism shapes from owner-side mod paths with real runtime evidence.

The examples do not contain game assets, private project code, private process material, or full feature designs.
