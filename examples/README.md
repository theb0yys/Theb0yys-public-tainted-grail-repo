# Working Examples

These are small mod projects you can copy, build, run, and change.

If you are new to modding, start with the guide for the thing you want to make. The guide will link you to the matching example.

## Choose the kind of project

- [Mono examples](mono/README.md) — C# mods for a Mono/BepInEx setup.
- [IL2CPP examples](il2cpp/README.md) — C# mods for an IL2CPP/BepInEx setup.
- [Hybrid examples](hybrid/README.md) — projects that combine in-game and external/runtime components.

Each runnable example explains what it changes, how to build and test it, what to change first, and which guide covers the mechanism in more detail.

## Real project examples

- [Mod project catalogue](mod-catalog/README.md) — all 106 top-level projects from the development workspace, distilled into the patterns each project demonstrates.
- [Importer pipelines](../guides/tasks/importers/README.md) — the Armour, Creature, and Weapon import processes.

The catalogue is broader than the runnable-example folders. It includes released mods, frameworks, diagnostics, research projects, prototypes, and blocked/superseded work where the lessons are still useful.

For Merlin content authoring, start with [First content authoring](../guides/getting-started/first-content-authoring.md).
