# Hybrid Examples

Examples that combine an in-game runtime with an external client or another integration boundary.

- [TGE authenticated handshake](infrastructure/tge-authenticated-handshake/README.md) — authenticate an external client against an already running FoA/TGE runtime.
- [TGE-owned encounter](encounters/tge-owned-encounter/README.md) — use the reviewed TGE encounter service.
- [Temporary native actor](encounters/temporary-native-actor/README.md) — create a bounded temporary actor through the reviewed encounter service.

The encounter examples assume TGE is already installed, enabled, authenticated, and running. These examples do not install or launch the game.
