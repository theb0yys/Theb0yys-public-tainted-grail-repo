# Mono Harmony Examples

Use these examples to learn the common Harmony patch shapes used by Mono/BepInEx 5 mods before targeting FoA methods directly.

The examples cover a self-test patch, a guard that can block one action, and a Postfix that adjusts a returned result while preserving the original method.

- [Self-test](self-test/README.md)
- [Result postfix](result-postfix/README.md)
- [Action guard](action-guard/README.md)
