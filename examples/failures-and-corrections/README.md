# Failures and Corrections

Document type: **case-study index**.

This surface is for public-safe histories where an initially plausible model failed or proved incomplete and the correction teaches a reusable reasoning pattern.

A case should preserve:

```text
intended capability
→ plausible initial model
→ observed symptom / contradictory evidence
→ corrected owner or lifecycle
→ intervention change
→ proof
→ remaining limits
```

Do not manufacture cases from private material that has not been explicitly converted for public use.
